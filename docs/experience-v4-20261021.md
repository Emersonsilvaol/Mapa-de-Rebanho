# Mapa de Rebanho — Experience V4

Camada visual comum, sem alterações no motor de movimentação, conciliação ou segurança. Atalhos só abrem os módulos já autorizados pelo controle existente; preferências de visualização são locais ao navegador. Filtro de seção se aplica apenas quando a tela atual dispõe de filtro nativo compatível. A V4 não altera o saldo, as exportações ou o banco de dados.
